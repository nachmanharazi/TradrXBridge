# TradrXBridge

This repository contains a marketing-style landing page for the TradrXBridge website. The page includes a hero section, feature highlights, workflow overview, customer insight metrics, and a lightweight contact form to help communicate the product story.

To preview the site, open `index.html` in a web browser. It uses `style.css` for styling and `script.js` for interactive enhancements such as dynamic feature cards, smooth scrolling, and contact form acknowledgement. No build step or additional dependencies are required.
